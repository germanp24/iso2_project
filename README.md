# CodeChest - Food Delivery Web App 🍔🚀

![UCLM Logo](https://www.uclm.es/images/logos/Logo_uclm.png)

## Software Engineering II Project (2024-25)
Este repositorio contiene el proyecto final de la asignatura **Ingeniería del Software II** (curso 2024-25) desarrollado por el equipo **CodeChest**.

### Descripción 📌
Aplicación web de delivery de comida que permite a los usuarios realizar pedidos online, consultar el menú disponible y gestionar su cuenta de usuario. El proyecto ha sido desarrollado utilizando **Spring Boot**, **Maven** y **Java**, siguiendo principios de desarrollo ágil.

### Tecnologías Utilizadas ⚙️
- **Java 17**
- **Spring Boot**
- **Maven**
- **Apache Derby Embedded** (Base de datos)
- **Thymeleaf** (Motor de plantillas)
- **Bootstrap** (Interfaz de usuario)
- **Trello** (Gestión de tareas y metodologías ágiles)

### Metodología 🌀
El desarrollo se ha llevado a cabo siguiendo una metodología ágil basada en **Scrum**, con la planificación, asignación y seguimiento de tareas en **Trello**.

### Instalación 🚀
1. Clonar el repositorio:
   ```bash
   git clone https://github.com/CodeChest/food-delivery.git
   ```
2. Acceder al directorio del proyecto:
   ```bash
   cd food-delivery
   ```
3. Compilar el proyecto con Maven:
   ```bash
   mvn clean install
   ```
4. Ejecutar la aplicación:
   ```bash
   mvn spring-boot:run
   ```
